# Changelog

## [0.1.0a1] - 2026-10-05

First alpha.

### Added

- `nodestep.css`: tokens, a warm light theme and a dark theme, the app shell and the components shared by the nodestep sandbox, nodeartifact and text-to-sql-demo.
- `nodestep-theme.js`: the light and dark theme button, which stores the choice in the browser, and the search field's clear button.
- `nodestep-data.js`: search, expand and collapse, and copy for the data viewer.
- `demo.html`: every component with the markup to copy.
